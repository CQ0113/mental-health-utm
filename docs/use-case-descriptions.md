| Use Case Name       | Onboard Counselor                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Description         | Allows the Admin to register a counsellor or PPsi record so the counsellor can access appointment, slot, attendance, caseload, and assessment functions.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| User Story          | As an Admin, I want to register counsellor or PPsi records, so that counsellors can access appointment, slot, attendance, caseload, and assessment functions. |
| Actor(s)            | Primary actor: Admin<br>Secondary actor: Counselor                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Pre-condition(s)    | 1. Admin is authenticated.<br>2. Admin has permission to access the Counsellor (PPsi) management page.<br>3. Counselor record does not already exist with the same PPsi number, staff identifier, or email.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Normal Flow(s)      | - NF<br>1. The use case begins when the Admin opens the Counsellor (PPsi) list from the admin portal.<br>2. The system displays existing counsellor records, search filters, category filters, status filters, and an Add Counsellor option.<br>3. If the Admin clicks Add Counsellor and saves a new record, AF 1 is performed.<br>4. If the Admin searches or filters counsellor records, AF 2 is performed.<br>5. If the Admin cancels the operation, AF 3 is performed.<br>6. The use case ends.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Alternative Flow(s) | 1. Add counsellor record (AF 1)<br>1.1. System displays the Add Counsellor (PPsi) form.<br>1.2. Admin fills in required details such as PPsi number, counsellor name, organization, location, category, status, email, and contact details.<br>1.3. Admin clicks the save button.<br>1.4. If required details are missing or invalid, EF 1 is performed.<br>1.5. If a duplicate counsellor record is detected, EF 2 is performed.<br>1.6. System asks Admin to confirm the save action.<br>1.7. Admin confirms the action.<br>1.8. System saves the counsellor record and displays a success message.<br>1.9. The use case ends.<br><br>2. Search or filter counsellor record (AF 2)<br>2.1. Admin enters a search keyword or selects a filter.<br>2.2. System displays counsellor records matching the keyword, category, or status.<br>2.3. If no matching record is found, EF 3 is performed.<br>2.4. The use case ends.<br><br>3. Cancel operation (AF 3)<br>3.1. System hides the add form or redirects Admin to the previous page.<br>3.2. The use case ends. |
| Exception Flow(s)   | 1. Invalid or incomplete counsellor details (EF 1)<br>1.1. System displays an error message indicating that required fields must be completed before saving.<br>1.2. Use case resumes at AF 1 (1.2).<br><br>2. Duplicate counsellor record (EF 2)<br>2.1. System displays an error message indicating that the PPsi number, staff identifier, or email already exists.<br>2.2. Use case resumes at AF 1 (1.2).<br><br>3. No counsellor record found (EF 3)<br>3.1. System displays an empty state or no matching results message.<br>3.2. Use case resumes at AF 2 (2.1).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Post-condition(s)   | 1. A new counsellor profile is stored in the system after successful onboarding.<br>2. The counsellor becomes available for appointment assignment, slot setup, and counsellor portal access.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

| Alternative Flow(s) | 1. Search client profile (AF 1)<br>1.1. System retrieves matching client records.<br>1.4. If the search criteria is invalid, EF 1 is performed.<br>1.5. If no matching client profile is found, EF 2 is performed.<br>1.6. System displays matching client profiles.<br>1.7. The use case resumes at NF (4).<br><br>2. View selected client profile (AF 2)<br>2.1. User selects a client record from the result list.<br>2.2. System verifies the user's permission to view the selected profile.<br>2.3. If the user is not authorized, EF 3 is performed.<br>2.4. System displays client profile sections such as personal information, study or service information, marriage information, health history, confirmation, appointment information, and brief case file.<br>2.5. | Exception Flow(s)   | 1. Invalid search criteria (EF 1)<br>1.1. System displays an error message indicating that the search criteria is invalid.<br>1.2. Use case resumes at AF 1 (1.2).<br><br>2. Client profile not found (EF 2)<br>2.1. System displays a message indicating that no client profile matches the search.<br>2.2. Use case resumes at AF 1 (1.2).<br><br>3. Unauthorized profile access (EF 3)<br>3.1. System displays an access denied message.<br>3.2. System redirects user to the previous page.<br>3.3. The use case ends.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Post-condition(s)   | 1. Authorized user can view the selected client profile.<br>2. No client information is changed unless the user performs a separate update action.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

| Use Case Name       | Join Online Session                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Description         | Allows a Client or Counselor to join an approved online counselling session using the meeting link generated for an online appointment.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| User Story          | As a Client or Counselor, I want to join an approved online counselling session from its appointment record, so that I can attend the scheduled session through the meeting link. |
| Actor(s)            | Primary actors: Client, Counselor<br>Secondary actor: System                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Pre-condition(s)    | 1. User is authenticated.<br>2. Appointment is approved or ongoing.<br>3. Appointment session type is Online.<br>4. Meeting link has been generated for the appointment slot.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Normal Flow(s)      | - NF<br>1. The use case begins when the Client or Counselor opens an online appointment record.<br>2. The system displays appointment details, session type, date, slot, counsellor, and meeting link or Join button.<br>3. If the user clicks the Join button, AF 1 is performed.<br>4. If the user tries to join before the session is available, AF 2 is performed.<br>5. If the user cancels the operation, AF 3 is performed.<br>6. The use case ends.                                                                                                                                                                                                                                                                                                                                                                                                           |
| Alternative Flow(s) | 1. Join online meeting (AF 1)<br>1.1. System validates the appointment reference, user identity, session type, and meeting link.<br>1.2. If the meeting link is missing, expired, or invalid, EF 1 is performed.<br>1.3. If the user is not authorized for the appointment, EF 2 is performed.<br>1.4. System opens the online meeting link.<br>1.5. System records the join event and triggers TA04 Auto-log Attendance(Online) as the online-session extension of TA02 Record Attendance.<br>1.6. The use case ends.<br><br>2. Session not yet available (AF 2)<br>2.1. System displays a message indicating that the online session is not yet open.<br>2.2. User remains on the appointment details page.<br>2.3. The use case ends.<br><br>3. Cancel operation (AF 3)<br>3.1. System redirects user to the previous appointment page.<br>3.2. The use case ends. |
| Exception Flow(s)   | 1. Invalid meeting link (EF 1)<br>1.1. System displays an error message indicating that the meeting link cannot be opened.<br>1.2. Use case resumes at AF 1 (1.1).<br><br>2. Unauthorized session access (EF 2)<br>2.1. System displays an access denied message.<br>2.2. System redirects user to the appointment list.<br>2.3. The use case ends.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Post-condition(s)   | 1. User joins the online counselling session successfully.<br>2. The online join event is available for auto-attendance processing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
